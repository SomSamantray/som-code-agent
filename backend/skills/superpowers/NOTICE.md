# Bundled Superpowers Skills Notice

SOM-CODE bundles selected skill files from `obra/superpowers` so packaged installs have strong default process skills available through `skill_list`, `skill_search`, and `skill_view`.

- Source: https://github.com/obra/superpowers
- License: MIT
- Bundled form: `skills/*/SKILL.md` directories copied under `backend/skills/superpowers/`
- Naming policy: source skill names are preserved exactly from each `SKILL.md` frontmatter.

The upstream repository's MIT license applies to these bundled skill documents.
